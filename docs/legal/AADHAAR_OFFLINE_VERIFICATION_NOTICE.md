## 1. Strictly Voluntary Option
Submitting Aadhaar Offline XML or Secure QR proof on COVERLY is **100% voluntary**. COVERLY does **not** require Aadhaar for account creation, marketplace access, or B2B identity verification.

## 2. Non-Aadhaar Alternatives Always Available
Every user who prefers not to use Aadhaar Offline verification may complete Identity Verification using an alternative government-issued photo identification document, including:
- Permanent Account Number (PAN) Card
- Valid Indian Passport
- Driving Licence
- Election Commission Voter ID Card

Choosing an alternative ID carries no penalty and grants the exact same `Identity Verified` badge upon compliance review.

## 3. Zero Raw Aadhaar Number Storage
- COVERLY does **not** request, collect, log, or store raw 12-digit Aadhaar numbers or biometric data.
- COVERLY does **not** perform unauthorized UIDAI portal scraping or claim direct UIDAI e-KYC API integration unless formally licensed as an authorized KUA/AUA and explicitly disclosed.
- Where a user voluntarily uploads an offline proof, only masked reference indicators (at most last 4 digits where applicable) and verification outcome metadata are persisted.

## 4. User Responsibilities
Users choosing voluntary Aadhaar Offline submission should ensure any uploaded copy is masked or generated via UIDAI's official offline paperless e-KYC / masked Aadhaar tools and must not enter an unmasked 12-digit Aadhaar number in free-text fields.
